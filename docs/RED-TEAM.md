# Full Plate — red-team review (master 95c5ab0, 10 Nov 2026)

> **Round 11 status** (last column): fixes from r11-a … r11-e merged and re-tested in the Round 11 review (docs/REVIEW.md "Round 11"). Closed = the reproduction no longer reproduces; Partly = the player-facing problem is fixed but something listed remains.

Three independent adversarial passes, none of which fixed anything: security & data, simulation & economy, player experience & test honesty. Reproduction scripts, crafted files and screenshots live in the session scratchpad under `redteam/{sec,sim,ux}/`; the sim fuzzers are runnable with `npx tsx` and the security harness with `vitest --config redteam/sec/harness/vitest.config.mjs`.

**Headline.** No code execution, no third-party data flow, no infinite-money exploit, no crash a player can reach by playing, no flaky or assertion-free tests. The serious findings are (1) a single crafted save file can brick the game on every device signed into that account, (2) three design dead-ends — losing the hands-on shop deletes a whole profitable Empire, a Cosy player with no staff can be stuck at £0 forever, the Michelin dynasty win is close to unreachable — and (3) an iPad held upright can't play at all.

## Severity key
P0 — exploitable or game-breaking now, no in-game recovery · P1 — likely to lose the player's game or make her quit · P2 — should fix · P3 — tidy-up.

## What held up (tried and failed to break)
- **Input hardening:** malformed/empty/null/wrong-magic/wrong-encoding/200k-deep JSON refused with a child-readable message; prototype pollution never reaches `Object.prototype`; HTML/script in names inert everywhere (React escaping, no `innerHTML`/`eval` in the bundle); download/PNG filenames slugged.
- **Privacy:** account data under the private per-viewer prefix (verified against the db rules: another uid reads 0 docs, writes rejected); only the opaque user id is used; no name/email scope; **zero third-party requests** — self-hosted fonts, no analytics, no source maps, no console logging.
- **Economy:** 1,932 fuzzed game-days with junk arguments broke no invariant (integer cash, no NaN, stock ≥ 0, unique ids, byte-identical serialize, deterministic replay incl. save/load mid-run). Decor buy/swap/put-back/refresh never gains a penny; CANCEL_ORDER conserves money; franchise sell→buy-back loses £60–335k; borrowing cap can't be dodged; closing weak nights doesn't game the inspectors; no free skill from hire/fire churn.
- **Liveness:** 14,303 reducer actions across every save type — from every sampled state a sensible player could reach tomorrow (board meeting across reload, fitting nights, all staff off, unaffordable-only events). Dead states are economic, not phase-machine traps.
- **Saves:** all 33 corpus saves byte-identical after 30 days → save → load → 30 days vs an unbroken 60; state stays bounded over 3,000 days except `meta.parked`.
- **Tests:** 1,071 pass, 3/3 runs no flakes, zero assertion-free tests, no skip/only, no mocking of the code under test; sim-core 99 % line coverage.
- **Content:** 892 strings read — no insults, shaming, violence or death; no dark patterns; FK grade 2–4 sentences.
- **CI basics:** frozen lockfile, pinned pnpm, no lifecycle scripts, no PR trigger, typecheck + tests before deploy.

## Recommended order of work
1. **Harden loading (S1–S4, S10, G9–G13):** one `validateLoaded` schema for every deserialiser (types, ranges, string caps, array caps, finite numbers), re-serialise on import, size caps on file read and decompression, bounded chunk reads, `Object.hasOwn` dispatch, NaN guards in empire/stars, try/catch around autosave encode, a top-level error boundary with "Delete this game / Back to title", and per-slot (not whole-account) stall on `invalid_argument`.
2. **Stop silent losing (U3, U2, G2, U6):** a visible bank countdown chip and evening card; confirm purchases that leave < 3 days of running costs; visible "needs £X" text; hide/grey unaffordable advice and event options; let Cosy hire into the stock overdraft or start every game with one chef; archive instead of delete on game over.
3. **Empire/Stars end-game design (G1, G3–G8):** never treat a running Empire as over — HQ bail-out or switch site; HQ funds a visited till (no free £20k); hands-on only for company sites; prune `meta.parked`; bankruptcy screen; stars drop only below threshold − 2 (or lower ★★★ to ≈89) and re-run 20-seed 12-year headless to ≥ 50 % dynasties; make El Bulli an honourable ending, not the win.
4. **Tablet & child fit (U1, U4, U5, U7–U11):** portrait layout or rotate card; clear toasts on phase change; no quadrant label before ~7 days of sales; plain-word pass (86 → "Take off tonight", footfall → "people walking past", etc.) with `<Term>` tips for the rest; a "No grown-up drinks" setting on by default; glossary terms out of the tab order + skip link; owner "Skip to evening", remembered speed, Cosy quick year; autosave during shifts and resume hands-on.
5. **Account hygiene (S5, S6):** key the device cache by uid, never push/delete another uid's slots; cap packed size per slot, keep two backups, delete up to a chunk high-water mark.
6. **Pipeline (S7–S9, S13, T1–T4):** job-level permissions, SHA-pinned actions, drop `--host`, upgrade vite/vitest, ship `OFL.txt`; probe includes `.term`/disabled/switch/portrait/touch and the audit runs at 1024; assert lead-in as an aggregate over 16+ seeds; commit a distinct save corpus (incl. career and R8–R10) as CI fixtures; write a README and refresh ARCHITECTURE.md.
